# Boccia online Worker

- worker.js — HTTP-маршруты, создание комнат и передача WebSocket в Durable Object.
- room.js — соединения игроков, места, готовность, синхронизация и сохранение матча.
- game-engine.js — конфигурация, физика броска, инвентарь, правила и подсчёт очков.
- wrangler.jsonc — прежняя конфигурация Cloudflare; точка входа worker.js и экспорт BocciaRoom сохранены.

Развёртывание: npm install, затем npm run deploy в авторизованном Cloudflare-окружении. Существующая интеграция GitHub/Cloudflare также продолжает использовать worker.js.

Это ES-модули с явными импортами. Тела функций перенесены без изменения поведения. Правила клиента и сервера пока остаются отдельными реализациями; их унификация требует отдельного сравнения локального и онлайн-режимов.
